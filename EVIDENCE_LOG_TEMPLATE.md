# Evidence Log Template

Use one entry per authorized observation. Sanitize before publishing.

## Evidence entry
- Evidence ID:
- Date/time and timezone:
- Asset alias (do not publish real client identifiers):
- Authorization/scope reference:
- Tool and version:
- Command or action (remove sensitive values):
- Expected result:
- Actual result:
- Screenshot/log filename:
- Interpretation:
- Confidence and limitations:
- Reviewer:

## Publishing checklist
- [ ] No real client domain, IP, hostname, email, username, token, cookie, or password.
- [ ] No raw scan output that exposes a third-party system.
- [ ] No exploit payloads or instructions that enable unauthorized access.
- [ ] No personal or confidential authorization documents.
- [ ] Screenshots are cropped/redacted and belong to an authorized lab.
- [ ] Findings distinguish facts, operator reports, and hypotheses.
